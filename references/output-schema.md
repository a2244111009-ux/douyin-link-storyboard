# Output Schema

Use JSONL for backend ingestion. Keep raw extraction and cleaned/editorial fields separate.

## transcripts.jsonl

```json
{
  "aweme_id": "7509805323629219110",
  "video_path": "E:\\DouyinRuns\\run\\downloaded\\...mp4",
  "transcript_path": "E:\\DouyinRuns\\run\\transcripts\\...txt",
  "raw_transcript": "ASR text exactly as recognized",
  "clean_transcript": "human-corrected copy, empty until reviewed",
  "needs_review": true
}
```

```json
{

  "aweme_id": "7509805323629219110",
  "opening_type": "场景 + 反常识指令",

```

## timeline-draft.jsonl

Generated by the pipeline. Default rows are text/timecode based. If visual checking is needed, sample at most 10 temporary checkpoints per video, inspect internally, then delete them. Do not show screenshots to the user unless explicitly requested.

```json
{
  "aweme_id": "7509805323629219110",
  "shot_index": 1,
  "time_range": "0.00-2.00s",
  "frame_path": "",
  "voiceover": "这个夏凉被睡觉时候",
  "visual": "",
  "shot_purpose": ""
}
```

## storyboard.jsonl

Final reviewed storyboard rows:

```json
{
  "account": "creator nickname",
  "aweme_id": "7509805323629219110",
  "duration_seconds": 16.14,
  "shot_index": 1,
  "time_range": "0.00-1.60s",
  "frame_path": "",
  "visual": "女生站在床边，手提绿色夏凉被。",
  "voiceover": "这个夏凉被睡觉时候",
  "shot_purpose": "产品和使用场景同时出现。"
}
```

For user-facing Markdown, omit `frame_path` by default and show only:

```text
time_range | visual | code_blocks | motion_effects | voiceover | shot_purpose
```

For Codex/Remotion-style creator videos, `code_blocks` should capture reusable programmed elements such as text blocks, number cards, UI screenshots, phone mockups, charts, score badges, labels, masks, and highlight words. `motion_effects` should capture how those elements move or emphasize meaning, such as fade in/out, slide, scale, mask reveal, subtitle sync, glow, shake, progress, cursor/typing simulation, or word-level highlight.
